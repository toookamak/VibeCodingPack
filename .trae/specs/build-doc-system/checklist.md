# Checklist

## 格式与风格一致性

- [ ] 所有 12 篇新文档使用标准 Markdown 格式（标题层级、表格、代码块、引用块、checkbox）
- [ ] 所有文档使用 `#`/`##`/`###`/`####` 标题层级，不使用 `===` 分隔线作为标题
- [ ] 正反对比使用 Markdown 表格呈现
- [ ] 代码示例使用 ` ```ts ``` ` 等代码块
- [ ] 每篇结尾附快速参考卡
- [ ] 避免过度生活化口语化类比，保持通俗但专业
- [ ] 必要处增加结构图、树状图、流程图等可视化图表

## 术语统一

- [ ] 统一使用"实体""组件""模块""功能模块""数据层""业务层"等术语
- [ ] 文件命名统一使用 `XX-名称-mimo.md` 格式
- [ ] 版本号统一从 v1.0 起记
- [ ] 日期使用实际生成日期
