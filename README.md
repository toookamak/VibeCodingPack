## 快速开始

1. 从 [00-导读](00-导读与项目概述-mimo.md) 了解文档体系全貌
2. 根据角色选择阅读路径（决策者 / 开发者 / AI 协作）
3. 按开发阶段查阅对应文档
4. 用 [12-健康检查清单](12-健康检查清单-mimo.md) 做质量把关

## 风格规范

- **结构**：篇 → 章 → 节，每篇结尾附快速参考卡
- **表达**：通俗但专业，避免过度口语化
- **示例**：使用通用场景（博客平台、电商后台），不绑定特定项目
- **图表**：必要处使用 ASCII 结构图、流程图、决策树
- **术语**：统一使用"实体""组件""模块""功能模块""数据层""业务层"

## 许可

个人使用，内部工程规范文档。
